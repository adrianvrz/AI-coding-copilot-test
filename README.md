## Overview
Bucks2Bar is a web application designed to provide users with an engaging experience related to bartering and trading. The application utilizes Bootstrap for responsive design and includes custom styles and interactive JavaScript for a modern user experience.

## Features
- **Responsive Design**: Ensures optimal viewing experience across devices.
- **Custom Styles**: Provides a modern and unique look.
- **Interactive JavaScript**: Adds dynamic and engaging user interactions.

## Installation

### Prerequisites
- Node.js (v14+)
- npm

To get started with the Bucks2Bar project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/bucks2bar.git
   ```
2. Navigate to the project directory:
   ```bash
   cd bucks2bar
   ```

## Usage
- The main entry point for the application is `index.html`.
- Custom styles can be modified in `css/styles.css`.
- JavaScript functionality can be found in `js/main.js`.

## Running the App Locally

1. Install backend dependencies:
   ```bash
   cd backend && npm install
   ```
2. Create a `.env` file in `backend/` with your email credentials.
3. Start the backend:
   ```bash
   npm start
   ```
   or
   ```bash
   node app.js
   ```
4. Visit `http://localhost:5000` in your browser.

## Example Usage
Visit `http://localhost:5000` and create an account to start bartering items.
